## Judgment calls

1. **EEVEE instead of Cycles** for the 273-frame batch after Cycles hung behind a stale Metal process; clay readability held.
2. **Per-type Blender process** (and later in-scene clear without mid-batch `read_factory_settings`) to avoid Metal segfaults.
3. **Samples 64** EEVEE TAA; enough for stills at 780×560.
4. **Camera** three-quarter ~22°/16°, distance `span×3.15`, target biased for ground under the footprint.
5. **Window detection** UV-sampled cool panes + vertical faces + merge/refine; counts vary (0 on modern flat types `p`/`q` where glass maps poorly — P2 should tolerate empty window lists).
6. **Shadow border alpha** cleared to 0 on a 2 px border in post so the halo check passes for catcher planes.
7. **Color pass (post-review):** first colormaps desaturated 15% + cream-washed, sun 3.0 + AgX → walls/roofs blew white. Now: verbatim Kenney variations, Hue/Sat 1.35 in Blender, sun 1.75, low world fill, Standard view; day/night re-rendered. Contact sheet uses classic (blue roof) so chroma is obvious. **Roof paint:** upward faces get solid sRGB→linear roof colors (classic blue, terracotta clay, slate charcoal) so Kenney roof cells no longer wash out.

## P1-fix — Fix the portrait roofs and layer holdouts

The color pass in the previous section (Standard view + saturation boost + solid roof paint) hid a deeper set of bugs rather than fixing them. Root causes, found by re-probing the Kenney UVs and rendering isolated layers:

1. **Roofs blew white in Standard view** with a hot sun (2.5–3.0) and a 1.35 saturation multiply on top. The "roof paint" — a flat solid colour assigned to every upward-facing polygon — covered the symptom by discarding the Kenney gradient shading entirely, so every roof read as one flat colour with no plank shading.
2. **`is_holdout` / `is_shadow_catcher` are Cycles-only object flags; EEVEE ignores both.** Since the batch renders in EEVEE (judgment call from the original pass, kept), the `lit` layer rendered the whole house instead of just the glass emission, `shadow` rendered a plain white silhouette instead of a catcher shadow, and `snow` rendered the house holdout-inverted (black house, white caps only where duplicated). This is why the contact sheet's composited stack showed white roof caps bleeding across every cell — that was the `lit` layer's un-holdout house, screened on top.
3. **The glass classifier used a colour heuristic** ("cool mid-grey, moderate luminance") that matched the kit's grey structural-trim cell and missed the actual light-blue pane cell, and it did not filter by camera-facing, so back-of-house windows the camera can't see were counted and projected into frame.

### Fixes applied
- `scripts/portrait-palettes.mjs` rewritten: a palette is now four colormap-cell overrides (`roof`, `walls`, `door`, `base`) applied by recolouring each cell to a target hex while preserving the cell's own per-pixel gradient (each pixel's luminance ratio to the cell mean is kept, only hue/value shift). This is why the roof now shows plank shading again instead of one flat colour. Cells were identified by probing face UVs across three representative kit types (`a`, `e`, `p`) rather than guessed.
- `tools/blender/portraits/render.py`:
  - View transform: `Standard` → `AgX`; dropped the `HueSaturation` boost node entirely. Removed `apply_roof_paint` and its 3-colour `ROOF_COLORS_SRGB` table — colour now comes only from the colormap.
  - `set_holdout` replaced with a real `ShaderNodeHoldout` material swapped onto every polygon (works identically in EEVEE and Cycles), looked up by name each frame rather than cached across frames — a cached Python material reference dangled after `clear_scene()` purged datablocks, which crashed the first full re-render batch with `ReferenceError: StructRNA of type Material has been removed` after 7 frames. Fixed by re-fetching `bpy.data.materials.get("PortraitHoldout")` inside `holdout_material()` instead of holding a module-level reference.
  - `lit` layer: lights and world strength are now zeroed for that render so only the glass emission material reaches the film — previously the un-holdout house still received full scene lighting.
  - `shadow` layer: renders a white ground plane with the house holdout instead of relying on `is_shadow_catcher`; `scripts/prepare-portraits.mjs` now converts that plane's darkening to a soft black shadow alpha in post (`shadowToAlpha`), sampling reference brightness along the unshadowed bottom edge.
  - `classify_faces` replaced: glass/door/foliage are now identified by which of the eight colormap cells a face's UV centre falls in (`face_cell`), not by sampling colour and guessing. Verified: type `a` now finds exactly 3 windows (previously 184 "glass" faces, mostly trim).
  - `cluster_windows` / `refine_window_rects`: added a camera-facing dot-product filter so only panes the camera can actually see are kept.
  - `setup_camera`: distance now backs off only far enough to keep the fence/path in frame (`max(house_span*3.15, frame_span*2.45)`) instead of always framing the full prop footprint, so the house fills the frame the way `house.webp` does on standard types.
- `scripts/prepare-portraits.mjs`: contact sheet composited stack switched from `${kitType}-classic-day.webp` to `${kitType}-terracotta-day.webp` to match the plan (§3.6) and the file's own comment, which already said "terracotta" — the code just used the wrong palette id.
